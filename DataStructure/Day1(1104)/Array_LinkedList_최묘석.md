## 1. 개요 및 정의

> Array와 LinkedList의 차이와 각각의 메모리 구조를 정리.

- **Array(배열)**: 같은 종류의 데이터를 연속된 메모리 공간에 저장하는 자료구조이다. 인덱스를 이용해 원하는 위치에 바로 접근할 수 있다.
- **LinkedList(연결 리스트)**: 각 노드가 데이터와 다음 노드에 대한 참조를 가지며, 노드들이 연결되는 자료구조이다. 노드 자체는 메모리에 연속해서 저장될 필요가 없다.
- **등장 배경**: 배열은 인덱스 접근이 빠르지만, 크기가 고정된 배열에서는 크기 변경이 어렵고 중간 삽입·삭제 시 데이터를 이동해야 한다. 연결 리스트는 노드의 연결 관계를 변경하는 방식으로 이러한 문제를 보완한다.

---

## 2. 핵심 동작 원리 및 특징

> 교육자료에는 C++과 Java 코드가 많아, 익숙한 Python을 기준으로 구조를 이해하려고 함.

- **Array의 메모리 구조**: 요소가 연속된 위치에 저장되어 인덱스로 바로 접근할 수 있다. 다만 Python의 `list`는 값을 직접 연속 저장하는 일반적인 고정 배열과 달리, 객체에 대한 참조를 연속적으로 관리하는 **동적 배열**이다.
- **LinkedList의 메모리 구조**: `[데이터 | 다음 노드 참조] → [데이터 | 다음 노드 참조] → None` 형태이다. 중간에 노드를 추가할 때는 주변 노드의 참조를 변경하지만, 해당 위치를 찾는 과정은 별도로 필요하다.

**Python으로 이해한 예시**

```python
# Python list: 인덱스로 바로 접근
arr = [10, 20, 30]
print(arr[1])  # 20

# 단일 연결 리스트: 다음 노드를 참조
class Node:
    def __init__(self, data):
        self.data = data
        self.next = None

head = Node(10)
head.next = Node(20)
head.next.next = Node(30)

print(head.next.data)  # 20
```

| 구분           | Array                       | LinkedList (단일 연결 리스트)                 |
| :------------- | :-------------------------- | :-------------------------------------------- |
| 메모리 구조    | 연속된 공간에 요소 저장     | 떨어진 노드를 참조로 연결                     |
| 장점           | 인덱스 접근이 빠름          | 노드 연결 변경으로 삽입·삭제 가능             |
| 단점           | 중간 삽입·삭제 시 요소 이동 | 순차 탐색 필요, 참조 저장 공간 추가           |
| 인덱스 접근    | O(1)                        | O(n)                                          |
| 중간 삽입·삭제 | O(n)                        | 위치를 이미 알면 O(1), 탐색까지 포함하면 O(n) |

※ 위 Array는 일반적인 배열의 특성을 기준으로 비교했다. Python `list`도 인덱스 접근은 O(1)이지만 크기가 동적으로 늘어난다.

## 3. 실무 / 면접 핵심 포인트

### Q1. LinkedList의 삽입·삭제가 Array보다 항상 빠른지 설명하시오.

- **A**: 아닙니다. 삽입하거나 삭제할 노드의 위치를 이미 알고 있다면 연결만 바꿔 O(1)에 처리할 수 있습니다. 하지만 해당 위치를 처음부터 찾아야 한다면 O(n)이 걸릴 수 있습니다. 따라서 삽입·삭제가 많다는 이유만으로 무조건 LinkedList가 유리한 것은 아닙니다.

### Q2. Python의 list가 Array와 LinkedList 중 어떤 구조인지 설명하시오.

- **A**: Python의 `list`는 동적 배열 기반입니다. 인덱스로 빠르게 접근할 수 있지만, 중간에 `insert()`나 `pop(0)`을 실행하면 다른 요소들의 참조를 이동시켜야 하므로 O(n)이 걸립니다. LinkedList와는 내부 구조가 다릅니다.

### 실제 활용 사례

**Array - 학생 점수 조회**

학생별 점수를 학번에 대응하는 인덱스로 관리하는 경우, 원하는 학생의 점수에 빠르게 접근할 수 있다.

- 데이터 조회가 빈번하고 중간 삽입·삭제가 적은 상황에 적합
- 인덱스를 알고 있다면 O(1)로 접근 가능

**LinkedList - 음악 재생 목록 수정**

현재 재생 중인 곡의 노드를 알고 있을 때, 그 다음에 새로운 곡을 추가하는 상황을 예시로 정리했다.

- 기존 요소 전체를 이동하지 않고 연결 관계를 변경
- 삽입 위치를 찾는 탐색까지 필요하면 O(n)이 걸릴 수 있음

### 학습하며 느낀 점

C++의 포인터와 Java의 ArrayList 개념을 Python의 `list`와 `Node` 클래스로 바꿔 살펴보며 메모리 구조의 차이를 정리했다.

Array는 인덱스를 통한 접근이 빠르고, LinkedList는 이미 알고 있는 노드 주변의 연결을 변경하기 쉽다는 점이 핵심이었다.

특히 **삽입·삭제가 많다고 해서 LinkedList가 항상 유리한 것은 아니며**, 탐색에 필요한 시간까지 고려해야 한다는 점을 확인했다.
