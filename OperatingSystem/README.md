# 🖥️ Operating System (운영체제)

> 백엔드 기술 면접에서 자료구조·네트워크 다음으로 많이 나오는 운영체제 핵심 개념을 정리하고 아카이빙하는 공간입니다.  
> 출처: [gyoogle 기술면접 가이드 - Operating System](https://github.com/gyoogle/tech-interview-for-developer#operating-system)

---

## 🧭 진행 방식 (제안)

- **시작 시점**: 자료구조 트랙이 8회차(B-Tree & B+Tree)로 끝나면, **9회차부터 DS 자리를 OS가 이어받습니다.** (DS + NW 2트랙 → OS + NW/AI 2트랙)
- **회차당 분량**: 기존처럼 회차마다 1~2개 주제, 발표자 3~4명이 나눠서 맡습니다.
- **흐름**: `프로세스·스레드 → CPU 스케줄링 → 동기화·교착상태 → 메모리 → 가상 메모리 → 시스템 콜·파일 시스템` 순으로, 앞 회차 개념을 다음 회차가 이어 쓰게 짰습니다.
- **발표 초점**: 개념 나열보다 **"그래서 내 서버 코드에서 왜 중요한가"** (예: 스레드 풀, DB 커넥션 락, 메모리 누수, `ulimit`)에 맞춰 주세요.
