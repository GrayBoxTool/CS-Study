# 🤖 AI (인공지능 기초 & LLM 활용)

> AI 모델을 직접 만드는 연구자가 아니라, **AI를 서비스에 붙이는 개발자** 관점에서 면접에 나올 만한 개념을 정리하고 아카이빙하는 공간입니다.

---

## 🧭 진행 방식 (제안)

- **시작 시점**: 네트워크 트랙이 끝나면 **NW 자리를 AI가 이어받습니다.** (OS 트랙과 같은 회차에 병행)
- **범위**: 스터디원 대부분이 비전공 백엔드 지향이라 수식·논문보다 **"개념을 말로 설명할 수 있는가"**와 **"백엔드에서 어떻게 붙이는가"**에 초점을 둡니다.
- **흐름**: `머신러닝 기초 → 학습 원리 → 딥러닝 → Transformer·LLM → LLM 서비스 개발(RAG 등)` 순으로 쌓아 올립니다. 앞 3개는 개념, 뒤 2개는 실무 활용입니다.
- **발표 초점**: 각 주제마다 **"면접에서 30초로 설명하기"** 한 문단을 꼭 넣어 주세요.
